## Quick Assessment Checklist

### Step 1: Word Counts
- [ ] Count words in each source
- [ ] Source 1: 15-80 words?
- [ ] Source 2: 57-131 words?
- [ ] Source 3: 113-177 words?
- [ ] Source 4: 232-269 words?
- [ ] Total insert: 500-610 words?

### Step 2: Sentence Analysis
- [ ] Count sentences in each source
- [ ] Calculate average (words ÷ sentences)
- [ ] Target average: 10-14 words?
- [ ] Mix of short and long sentences?
- [ ] No sentences over 25 words?

### Step 3: Complexity Estimation
- [ ] Identify 3+ syllable words
- [ ] Calculate percentage of total
- [ ] Target: 10-15%?
- [ ] Source 3 at lower end (student voice)?
- [ ] Technical terms explained in context?

### Step 4: Content Preservation Check
After any revisions, verify:
- [ ] Source 1: Statistics/facts for Q1(a) preserved?
- [ ] Source 2: 2-3 quotable critical thinking concept examples preserved?
- [ ] Source 3: Methodology AND testable claim preserved?
- [ ] Source 4: Two distinct opposing positions preserved?
- [ ] Source 4: Both speakers have balanced word counts?

## Common Issues and Fixes

### Issue: Too Complex

**Symptoms:**
- F-K Grade > 9.0
- Flesch RE < 55
- Complex words > 16%

**Fixes:**
1. Break long sentences into shorter ones
2. Replace multi-syllable words with simpler synonyms
3. Remove unnecessary jargon
4. Add context for technical terms
5. Use active voice instead of passive

**Example:**
- ❌ BEFORE: "The implementation of comprehensive immigration reform necessitates multilateral cooperation between governmental entities."
- ✅ AFTER: "Better immigration laws need governments to work together."

### Issue: Too Simple

**Symptoms:**
- F-K Grade < 5.5
- Flesch RE > 78
- Complex words < 9%

**Fixes:**
1. Combine short choppy sentences
2. Add appropriate topic-specific vocabulary
3. Include more detailed explanations
4. Add qualifying phrases

**Example:**
- ❌ BEFORE: "Hunger is bad. People die. We must help."
- ✅ AFTER: "Hunger remains a significant global challenge, with millions of people facing food insecurity each year."

### Issue: Wrong Length

**Too Short:**
- Add relevant details, examples, or data points
- Expand on causes, effects, or perspectives
- Include additional statistics

**Too Long:**
- Remove redundancy
- Combine similar points
- Cut tangential information
- Focus on essential content for exam questions

### Issue: Source 3 Too Formal

**Symptoms:**
- Reads like academic research, not student project
- Third-person voice
- Complex methodology descriptions

**Fixes:**
1. Add first-person narrative ("I decided to...")
2. Simplify methodology descriptions
3. Use conversational transitions
4. Include student-appropriate limitations ("I only had time to...")

### Issue: Source 4 Imbalanced

**Symptoms:**
- One speaker has significantly more words
- One speaker has stronger evidence
- One position is obviously "correct"

**Fixes:**
1. Equalise word counts (within 20%)
2. Give each speaker similar evidence quality
3. Ensure both positions have valid reasoning
4. Remove loaded language that favours one side

## Readability Formulas Reference

### Flesch-Kincaid Grade Level
```
0.39 × (words/sentences) + 11.8 × (syllables/words) - 15.59
```
Indicates US grade level required to understand text.

### Flesch Reading Ease
```
206.835 - 1.015 × (words/sentences) - 84.6 × (syllables/words)
```
Score 0-100; higher = easier to read.

| Score | Difficulty | Education Level |
|-------|------------|-----------------|
| 90-100 | Very Easy | 5th Grade |
| 80-89 | Easy | 6th Grade |
| 70-79 | Fairly Easy | 7th Grade |
| **60-69** | **Standard** | **8th-9th Grade** ← TARGET |
| 50-59 | Fairly Difficult | 10th-12th Grade |
| 30-49 | Difficult | College |
| 0-29 | Very Difficult | College Graduate |
